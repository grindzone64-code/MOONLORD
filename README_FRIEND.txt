# SHRAVAN SELFBOT SETUP GUIDE

Brother, follow these steps to run the bot on your PC:

1. INSTALL REQUIREMENTS:
   Double-click on 'Install_All_Requirements.bat'. 
   Wait for it to finish downloading everything (Node.js, Python, etc.).

2. CONFIGURE TOKENS:
   Edit 'tokens.txt' and paste your Discord tokens (one per line).

3. START THE BOT (Run these in order):
   A. Run 'run_lavalink.bat' (IMPORTANT: This must be running for music).
   B. Run 'run_hcap.bat' (Optional: Only if you want AI to solve captchas).
   C. Run 'Start_Selfbot.bat'. ( Run this for all)

4. CONTROL PANEL:
   Open your browser and go to: http://localhost:5000

Enjoy! 🚀
